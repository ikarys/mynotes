Everything a quick note needs, nothing that slows it.

Never asks to save
Every edit is written to a local database as you type, on blur and on close. Closing a tab keeps the note.
Find anything with Ctrl P
Full-text search across every note you ever wrote, open or closed.
Rich text and pasted images
Select text to format it. Paste a screenshot or Markdown straight in.
Mind maps
Ctrl Shift M opens one. Tab adds a child, Enter a sibling. Export as PNG.
Tabs like Notepad
Ctrl N, Ctrl W, Ctrl Tab. The window reopens where you left it.
Yours, on your disk
Notes stay in %APPDATA%. Open .md or .txt, save back as Markdown or plain text.

Install in a few seconds.

Grab a file from the latest release:

  • setup.exe installs for your user only, no admin rights, with a Start menu entry and an uninstaller.
  • portable.exe runs from anywhere, nothing installed.

Both are unsigned, so Windows SmartScreen warns on first launch: click More info, then Run anyway. SHA256SUMS in the release lets you check the download.

Uninstalling keeps your notes unless you tick Delete the application data.

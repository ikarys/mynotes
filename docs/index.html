Ideas branch out. So do your notes.

Any note can be a mind map. Build it from the keyboard, as fast as you think, and export it as a PNG when it is ready to share.

  • Ctrl Shift M new mind map
  • Tab add a child, Enter add a sibling
  • F2 rename, right-click for more

Find anything with Ctrl P.

Full-text search across every note you ever wrote, open or closed. The notes list on the left groups them by day, pinned notes first.

Paste an image, keep writing.

Images go straight into the note with Ctrl V, between the text and checklists around them. They are saved with your notes, on your disk, and copy back out with the text.

Everything a quick note needs, nothing that slows it.

Never asks to save
Every edit is written to a local database as you type, on blur and on close. Deleted notes wait 30 days in the Trash.
Rich text and pasted images
Select text to format it. Paste a screenshot or Markdown straight in. Code blocks colour JSON and YAML. Ctrl H finds and replaces.
One shortcut away
Ctrl Alt Space shows or hides the window from anywhere. Closing it keeps mynotes in the tray; it reopens where you left it.
Yours, on your disk
No account, no cloud: the only network call is the update check, and Settings turns it off. Open .md or .txt, save back as Markdown or plain text.
Pin and lock
Pin a note to keep it at the top of the list. Lock it so it cannot be trashed by mistake; it stays editable. Both are one click on the note in the list.
Updates itself
The installed app updates from the … menu; each update is signature-checked.

Install in a few seconds.

Download Windows · Linux

Grab a file from the latest release. On Windows 10/11:

  • setup.exe installs for your user only, no admin rights, with a Start menu entry and an uninstaller.
  • portable.exe runs from anywhere, nothing installed.

Both are unsigned, so Windows SmartScreen warns on first launch: click More info, then Run anyway. Uninstalling keeps your notes unless you tick Delete the application data.

On Linux (Ubuntu 22.04 or newer, x86_64):

  • AppImage runs from anywhere once made executable, and updates itself. It needs FUSE 2 (libfuse2).
  • .deb installs with sudo apt install ./mynotes-…-linux-amd64.deb; the app points you to each new version.

On Wayland the Ctrl Alt Space shortcut does not work, and GNOME needs the AppIndicator extension for the tray icon. SHA256SUMS in the release lets you check any download.

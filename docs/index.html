mynotes

GitHub

Write it down now. Find it next month.

mynotes is a free notepad for Windows and Linux. Every note is kept as you type, and three letters of search bring any of them back.

Download for Windows 2.9 MB Also for Linux

You never save, you never name a file.

Every edit is written to disk as you type. Close the window mid-sentence; the sentence is there tomorrow. The days of New Text Document (3).txt are over.

Deleted notes wait 30 days in the Trash before they are erased.

Find any note in three letters.

One search covers every note you ever wrote, open or closed, by the words inside it. You never named a file, so there is nothing to remember.

Always one shortcut away, never in the way.

A shortcut shows the window from any app, already drawn. The rest of the time mynotes waits in the tray and uses no processor time.

Measured on a release build: how, and on which PC.

  • 5.3 ms from the shortcut to the window
  • 0 % CPU while it waits in the tray
  • 0.3 s to open from a cold start

More than plain text when you need it.

Checklists, pasted screenshots, coloured JSON and YAML, and Markdown pasted straight in. Select a word to format it.

When a note turns into a plan, make it a mind map.

Any note can become a mind map, and it grows from the keyboard: Tab adds a branch, Enter adds a sibling. When it is ready to share, export it as a PNG.

Your notes stay on your PC.

There is no account and no cloud. The only network call is the update check, and Settings turns it off. Notes open from and save back to .md or .txt whenever you want a file.

Free and open source under the MIT licence. Read the code.

Install

Windows 10 and 11

setup.exe installs for your user only, without admin rights. portable.exe runs from anywhere.

Both are unsigned, so SmartScreen warns on first launch: click More info, then Run anyway.

Linux

An AppImage that updates itself, or a .deb, for Ubuntu 22.04 or newer on x86_64.

The AppImage needs libfuse2. On Wayland the global shortcut does not work.

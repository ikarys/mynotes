Ideas branch out. So do your notes.

Any tab can be a mind map. Build it from the keyboard, as fast as you think, and export it as a PNG when it is ready to share.

  • CtrlShiftM new mind map
  • Tab add a child, Enter add a sibling
  • F2 rename, right-click for more

Everything a quick note needs, nothing that slows it.

Never asks to save
Every edit is written to a local database as you type, on blur and on close. Closing a tab keeps the note; deleted notes wait 30 days in the Trash.
Find anything with Ctrl P
Full-text search across every note you ever wrote, open or closed.
Rich text and pasted images
Select text to format it. Paste a screenshot or Markdown straight in. Code blocks colour JSON and YAML. Ctrl H finds and replaces.
Tabs like Notepad
Ctrl N, Ctrl W, Ctrl Tab. Drag tabs to reorder them. The window reopens where you left it.
Yours, on your disk
No account, no cloud: the only network call is the update check, and Settings turns it off. Notes stay in %APPDATA%; open .md or .txt, save back as Markdown or plain text.
Light or dark
Follows the Windows theme, or pick one. Choose the font and size of your notes.

Install in a few seconds.

Grab a file from the latest release:

  • setup.exe installs for your user only, no admin rights, with a Start menu entry and an uninstaller.
  • portable.exe runs from anywhere, nothing installed.

Both are unsigned, so Windows SmartScreen warns on first launch: click More info, then Run anyway. SHA256SUMS in the release lets you check the download.

The installed app updates itself from the … menu; each update is signature-checked. Uninstalling keeps your notes unless you tick Delete the application data.

mynotes is written with AI assistance. Every number on this page was measured on the release build; how each claim is checked is in VERIFICATION.md.

# Contributing

mynotes is a personal tool maintained by Ikarys <bikarys@proton.me>.
Issues and pull requests are welcome.

## AI-assisted contributions

Accepted with disclosure. Every commit with AI-written content ends with an
`Assisted-by: <Tool>:<model>` trailer, one per model. You must have read and
understood every line you submit.

## What a pull request carries

- `just test` and `just lint` pass; say so in the description.
- For UI changes, what you checked by hand in the Windows exe.
- A new dependency names its registry check (exact name, maintained,
  current version).

See [VIBECODING.md](VIBECODING.md) and [AGENTS.md](AGENTS.md).
